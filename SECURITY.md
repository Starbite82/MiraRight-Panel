# Sicherheitsprobleme melden

Bitte melde vermutete Sicherheitslücken vertraulich an **info@mc-blub.de**.
Veröffentliche ausnutzbare Details zunächst nicht als öffentliches Issue.
Die Kontaktangaben stehen auch im [Impressum](IMPRINT.txt).
Wie deine Meldung verarbeitet wird, erklären die [Datenschutzhinweise](DATENSCHUTZ.txt).

Hilfreich sind Programmversion, Windows-Version, betroffene Komponente und
eine Beschreibung, wie sich das Problem nachvollziehen lässt. Sende keine
Passwörter, vollständigen Speicherabbilder oder unbereinigten persönlichen Dateien.

Das Projekt wird in der Freizeit gepflegt. Eine feste Antwort- oder Behebungsfrist
kann nicht zugesichert werden. Bitte verwende die neueste verfügbare Version;
für ältere Versionen gibt es keine zugesagten Sicherheitsupdates.

Die Oberfläche läuft mit normalen Benutzerrechten. Für zusätzliche Sensoren
kann der separate Sensorprozess erhöhte Rechte anfordern. Der Vorschaumodus
greift nicht auf USB-Displays zu und fordert keine Administratorrechte an.
