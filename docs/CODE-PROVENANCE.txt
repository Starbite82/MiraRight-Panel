CODE ORIGIN / USB REFERENCE

The initial commit cda9dd1 records the TRCC Linux bulk_lcd.py and protocol.py
as references for the Thermalright USB protocol. The Windows implementation
was written in C# against WinUSB; it was not copied verbatim from the Python file.
That observation alone does not prove legal independence or clean-room provenance.
Magic bytes, offsets, byte order and packet sizes are interface facts; expressive
code adaptation and the license grant are separate questions.

The exact upstream revision viewed during initial development was not recorded.
The present audit therefore makes no claim of a fully documented clean-room process.
A GPL-compatible licensing treatment is proposed to the owner conservatively.
No project license is changed until that decision is made.
